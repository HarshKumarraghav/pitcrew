glossary · tip: hover any dotted label for a one-line explanation
alias
Short name your tools use (coder, small), mapped to a real model.
context
How much text a model reads per request, in tokens (1 token ≈ ¾ word).
swap
Disk used as overflow memory. Much slower than RAM.
DEGRADED
Low-memory mode: no new loads, idle models unloaded, one request at a time. It ends by itself.
EXCLUSIVE
One big model has the machine. The others wait.
eviction
An idle model unloaded to make room. It reloads when it is next needed.
kept warm
A small helper that stays loaded so quick jobs answer instantly.
outside pitcrew
A model another app loaded. Pit Crew counts it but leaves it alone.
p50 / p95
Typical value / worst 5%.
